What you type, and what bash getsЧто вы набираете и что получает bash

Windows paths become Linux paths, wildcards are left for bash, everything else reaches the utility as text.Пути Windows становятся путями Linux, шаблоны остаются для bash, остальное доходит до утилиты как текст.

  • /mnt/cpath translated by wslbinпуть, переведённый wslbin
>_PowerShell C:\proj
PS> rsync -av C:\proj\dist\ host:/srv/app/
$bash /mnt/c/proj
rsync -av /mnt/c/proj/dist/ host:/srv/app/

C:\proj\dist\→/mnt/c/proj/dist/-IC:\inc→-I/mnt/c/incOUT=C:\out→OUT=/mnt/c/outC:\proj\*.log→/mnt/c/proj/*.log

Only Windows paths change, trailing slash included. host:/srv/app/ stays as typed.Меняются только пути Windows, вместе с косой чертой в конце. host:/srv/app/ остаётся как набрано.

  • /mnt/cpath translated by wslbinпуть, переведённый wslbin
  • *.logexpanded by bashраскроет bash
>_PowerShell C:\proj
PS> rsync -av *.log C:\backup\
$bash /mnt/c/proj
rsync -av *.log /mnt/c/backup/

Bash expands *.log by Linux rules in the current folder. Same for ?, [...] and a leading ~.Bash раскрывает *.log по правилам Linux в текущей папке. Так же ?, [...] и начальная ~.

  • \escape added by wslbinэкранирование от wslbin
>_PowerShell C:\proj
PS> awk '{print $1, $2}' data.txt
$bash /mnt/c/proj
awk \{print\ \$1,\ \$2\} data.txt

Braces, $, ;, |, quotes and spaces arrive as text: nothing typed can run a second command.Скобки, $, ;, |, кавычки и пробелы доходят как текст: набранное не запустит вторую команду.

Need $VAR, $(...) or a pipe inside Linux: --wslbin-sh or wslbin -c "...". To check without running: --wslbin-explain. Details in the README.Нужны $VAR, $(...) или пайп внутри Linux: --wslbin-sh или wslbin -c "...". Проверить без запуска: --wslbin-explain. Подробнее в README.

Pipes, Ctrl+C, exit codesПайпы, Ctrl+C, коды выхода

Input and output are not intercepted, so pipes, colours and full-screen programs work. The exit code is the utility's own.Ввод и вывод не перехватываются: пайпы, цвета и полноэкранные программы работают. Код выхода — код самой утилиты.

make build; $LASTEXITCODE

Wrappers on demandОбёртки по запросу

Creates wrappers and offers to install a missing utility with apt. --list shows them, --doctor checks the setup.Создаёт обёртки и предлагает поставить недостающую утилиту через apt. --list покажет их, --doctor проверит настройку.

wslbin --link make rsync

Made for AI agentsДля ИИ-агентов

Teaches Claude Code and Codex to use your Linux tools. --remove undoes it.Учит Claude Code и Codex пользоваться вашими Linux-утилитами. --remove всё отменяет.

wslbin --install-ai-context
