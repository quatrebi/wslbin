wslbin.ini

Файл лежит рядом с wslbin.exe (и с обёртками: они - копии). Простой текст, одна настройка в строке:
ключ = значение. Строка, начинающаяся с # или ;, - комментарий (комментариев в конце строки нет).
UTF-8. Неверная строка или неизвестный ключ - предупреждение с номером строки, остальное
используется. Ключи и имена утилит от регистра не зависят. Повтор ключа-списка (raw, sh, pass_env,
path) добавляет к нему; у остальных ключей берётся последний.

  distro = Ubuntu-24.04
      Дистрибутив, в котором работать. По умолчанию - дистрибутив WSL по умолчанию. wslbin --doctor
      перечисляет установленные.

  lang = ru
      Язык справки и wslbin --ai-context: en или ru. По умолчанию - язык Windows.

  raw = grep, sed
      Утилиты, которые всегда получают аргументы нетронутыми (как --wslbin-raw). Через запятую или
      пробел.

  sh = make
      Утилиты, которые всегда получают переменные Linux и $(...) (как --wslbin-sh). Если имя есть в
      обоих списках, побеждает raw. Опция в командной строке сильнее обоих.

  pass_env = KENV_*, APP_*, CI
      Переменные Windows, которые видят программы Linux (wslbin --help env).

  path = ~/.local/bin, ~/.cargo/bin
      Папки Linux, которые ставятся в начало PATH (только через запятую, так что в имени могут быть
      пробелы; ~ - домашняя папка Linux). Папка с двоеточием в имени пропускается.

  args.ls = --color=auto
      Аргументы, которые ставятся перед набранными. Разделяются пробелами; одинарные или двойные
      кавычки группируют слово: args.tool = "a b" c. С ними поступают так же, как с набранными.

Пример
  distro = Ubuntu-24.04
  raw = grep, sed
  sh = make
  pass_env = APP_*, CI
  path = ~/.local/bin
  args.ls = --color=auto
